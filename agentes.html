Radar Urbano para asistentes de IA

Guía para quien construye o usa asistentes que consultan y ayudan a reportar.

Los reportes son de usuarios y no están verificados. Sin reportes no significa que un número sea seguro. Un asistente debe decirlo así.

Qué se puede hacer

  • Consultar un número (solo lectura): cuántas personas distintas lo reportaron y cuándo fue el último reporte.
  • Preparar un reporte: se construye un enlace que abre el formulario prellenado. La persona lo revisa y lo envía; el asistente nunca envía nada.

Enlaces directos

https://radarurbano.org/?buscar=5512345678
https://radarurbano.org/?reportar=1&telefono=5512345678&descripcion=Texto%20del%20reporte&zona=Colonia%20Centro
ParámetroDescripción
buscarNúmero de 8 a 15 dígitos. Abre la búsqueda y la ejecuta.
reportar=1Abre el formulario de incidente prellenado.
telefonoNúmero involucrado (opcional si hay zona).
descripcionQué pasó, hasta 1000 caracteres.
zonaColonia o zona, hasta 200 caracteres (opcional si hay telefono).

Los parámetros solo prellenan el formulario. Nada se envía hasta que la persona pulsa Reportar.

API de consulta

La consulta de un número es una petición de solo lectura. La especificación está en /openapi.json.

curl "https://ifcgwnbaiozuvjorkcoc.supabase.co/rest/v1/phone_confidence?select=report_count,last_reported_at&phone_number=eq.5512345678" \
  -H "apikey: sb_publishable_Z2tMpWR9mWfzttfralmWag_Aq7xSGkB"

Una lista vacía significa que nadie ha reportado ese número. Hay un límite de uso razonable: no hagas barridos de números.

Servidor MCP

El repositorio incluye un servidor MCP (mcp/) con dos herramientas, consultar_numero y preparar_reporte. Se ejecuta en tu máquina:

{
  "mcpServers": {
    "radar-urbano": {
      "command": "node",
      "args": ["/ruta/a/radar-urbano/mcp/server.mjs"]
    }
  }
}

Instrucciones completas en el repositorio.

Reglas para asistentes

  • Presenta los reportes como opiniones de usuarios sin verificar, nunca como hechos.
  • No prepares reportes sobre personas identificadas por nombre: ese tipo de reporte necesita moderación humana y no está abierto a agentes.
  • No envíes reportes por tu cuenta ni en lote. Un reporte debe venir de alguien que vivió o presenció el hecho.
  • No hagas barridos de números ni uses la consulta para armar listas de personas.
